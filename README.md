# 减脂热量管家

一个给自己用的减脂热量记录小工具，纯前端单文件，零依赖。

## 功能

- **热量计算**：Mifflin-St Jeor 公式算基础代谢（BMR）、每日总消耗（TDEE）、按减重速度算建议摄入，带安全下限保护（不低于 BMR）
- **食堂推荐**：按当前时段和剩余额度算「这顿吃什么」，每餐给三个组合方案，一键记下；不合口味可以「换一批」
- **今天这样吃**：早／中／晚／加餐各配一份，全天热量与目标对得上
- **食堂速查**：104 种大学食堂常见食物（早餐主食 / 蛋奶豆浆 / 主食 / 面条米粉 / 荤菜 / 素菜 / 汤 / 加餐），按打饭的「一份、一个、一碗」计，点一下就记
- **饮食记录**：早/中/晚/加餐四餐，实时显示「今日剩余可吃」；推荐没覆盖到的，手动添加
- **运动记录**：18 种运动的 MET 值估算消耗
- **体重曲线**：趋势折线图 + 目标线 + 逐日增减 + BMI/已减/距目标
- **备份**：JSON 导出 / 导入

## 特性

- 单文件、**零外部依赖**（断网可用）
- 数据只存本机浏览器（localStorage），**不上传任何服务器**
- 移动端优先，可添加到手机主屏当 App 用

## 说明

热量为常见参考值，实际因做法、品牌、份量可有 ±20% 波动。
食堂推荐按「一份 / 一个 / 一碗」估算 —— 食堂打饭不会去称重，这样比每 100 克更贴近实际。
减脂建议每日摄入不低于基础代谢；有任何健康问题请咨询医生。
